# Simple Interest Calculator
A lightweight tool created for a micro-finance startup to help empower low-income individuals by making financial calculations transparent and accessible.

## Features
- Calculate simple interest based on principal, rate, and time.
- Clear output for total interest and total repayment amounts.
- Built with Python for ease of use and modification.

## How to Run
1. Ensure you have Python installed.
2. Run the script using: `python simple-interest.py`
